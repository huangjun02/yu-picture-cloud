## 1. 项目定位

一个**图库管理网站**：用户可以上传、管理、检索自己的图片，并支持对图片做压缩、格式转换、缩略图等处理。

- **目标用户**：需要集中管理图片的个人用户（起初只为学习，架构上保留扩展成多人协作空间的余地）
- **一句话价值**：把「散落在本地的截图、素材、照片」变成**可检索、可分享、可复用**的在线图库
- **项目性质**：个人学习项目，用于实践 Spring Boot 3 + Vue 3 全栈开发，**不以商业化为目标**

## 2. 用户角色与权限

| 角色 | 说明 | 能做什么 |
|---|---|---|
| **游客** | 未登录访问者 | 只能访问登录 / 注册页；任何涉及数据的接口一律拒绝 |
| **普通用户** | 已注册登录 | 上传、查看、编辑、删除**自己的**图片；管理自己的空间 |
| **管理员** | `userRole = 'admin'` | 普通用户全部权限 + 管理**所有人的**用户 / 图片 / 空间 |

**权限铁律**：任何"操作某个资源"的接口都必须做**归属校验**——只能操作自己名下的资源，管理员例外。这类越权漏洞不能靠前端隐藏按钮来防。

## 5. 数据模型

### 5.1 user 表 ✅

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | bigint | PK | 雪花 ID（MyBatis-Plus `ASSIGN_ID`） |
| userAccount | varchar(256) | NOT NULL，唯一索引 `uk_userAccount` | 账号 |
| userPassword | varchar(512) | NOT NULL | 密码**密文**，绝不存明文 |
| userName | varchar(256) | 可空 | 昵称 |
| userAvatar | varchar(1024) | 可空 | 头像 URL |
| userProfile | varchar(512) | 可空 | 简介 |
| userRole | varchar(256) | NOT NULL，默认 `user` | `user` / `admin` |
| createTime | datetime | NOT NULL，默认 CURRENT_TIMESTAMP | 创建时间 |
| updateTime | datetime | NOT NULL，默认 CURRENT_TIMESTAMP ON UPDATE | 更新时间 |
| isDelete | tinyint | NOT NULL，默认 0 | 逻辑删除：0 正常 / 1 已删除 |

**已落地的设计决策**：

1. **id 用雪花而非自增**：不暴露业务规模（自增 id 可被外人推算用户量）；代价是 19 位超出 JS 安全整数范围，**对外返回时必须序列化为字符串**
2. **账号唯一性由数据库唯一索引兜底**：不能只靠"先查再插"——并发下两个请求会双双通过检查
3. **逻辑删除**：图片、评论等数据会引用 user，物理删除会留下悬挂引用；同时保留撤销余地
4. **时间字段交给数据库默认值兜底**：即使应用层忘了填也不会是空值
5. **暂不引入 Bean Validation**：参数校验手写在业务层（个人偏好，避免框架注解入侵实体）

### 5.2 规划中的表（📋）

| 表 | 用途 | 关键点 |
|---|---|---|
| image | 图片元信息（名称、简介、分类、标签、尺寸、格式、大小、存储路径、所属用户 / 空间） | 逻辑删除；索引按 `userId`、`category`、`name` |
| space | 空间（名称、级别、容量额度、类型：私有 / 团队） | 逻辑删除 |
| space_user | 空间成员与角色 | 联合唯一索引 `(spaceId, userId)` |

## 6. 非功能需求

### 6.1 安全

- 密码**加盐加密**后存储，任何接口不得返回密码字段（用 VO 脱敏，不靠"记得别返回"）
- 所有涉及数据的接口必须登录校验；写操作必须校验资源归属（防越权）
- 19 位雪花 id 对外一律字符串化，防 JS 精度丢失导致误操作
- SQL 一律走 MyBatis-Plus 参数绑定，禁止字符串拼接
- 上传文件做「后缀白名单 + 内容校验 + 大小限制」，防伪装文件

### 6.2 性能

- 列表接口强制分页，默认每页 ≤ 20 条
- 单文件上传上限 5 MB（学习阶段）
- 列表页只加载缩略图，不拉原图
- 热点数据（如首页列表）按需引入 Redis / 本地缓存

### 6.3 兼容与部署

- 目标浏览器：Chrome 最新版（学习阶段不做多端兼容）
- 开发环境：本机运行，后端 8123 + 前端 5173 + MySQL 3306 + Redis 6379
- 单体部署，不做分布式 / 容器编排
